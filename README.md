<h1 align="center">RDP Cert Fix</h1>

<p align="center">Восстановление сертификата удалённого рабочего стола Windows, сломанного КриптоПро CSP.</p>

<p align="center"><img src="docs/screenshot.png" width="620" alt="Скриншот"></p>

## Проблема

На компьютере с КриптоПро CSP RDP перестаёт пускать: клиент сразу отваливается или пишет о внутренней ошибке, причём и из локальной сети. В журнале **System**:

- `TerminalServices-RemoteConnectionManager` **1057** - «не удалось создать новый самозаверяющий сертификат… Указан неправильный алгоритм»;
- `Schannel` **36870** - неустранимая ошибка при обращении к закрытому ключу, код `0x8009030D`.

Служба RDP не может ни открыть ключ своего сертификата, ни выпустить новый, поэтому рвёт каждое подключение на TLS-рукопожатии.

## Что делает программа

**Проверка** (при запуске и по кнопке «Проверить снова»):
включён ли удалённый рабочий стол, работает ли служба, порт, NLA, установлен ли КриптоПро, какой сертификат привязан и доступен ли его ключ службе, есть ли ошибки Schannel с момента запуска службы, и реальное рукопожатие RDP с `127.0.0.1`.

**Ремонт** (кнопка «Починить»):
1. Останавливает `UmRdpService` и `TermService`.
2. Удаляет сертификаты из `LocalMachine\Remote Desktop` и ранее выпущенные этой программой, вместе с ключами.
3. Выпускает самоподписанный сертификат `CN=<имя ПК>`: RSA-2048, SHA-256, Server Authentication, 10 лет. Ключ создаётся в штатном **Microsoft Software Key Storage Provider** в обход КриптоПро, службе (NETWORK SERVICE) выдаётся право чтения ключа.
4. Привязывает отпечаток к `RDP-Tcp` (`SSLCertificateSHA1Hash`).
5. Запускает службы и проверяет рукопожатие.

Активные RDP-сеансы при перезапуске службы отключатся, но не завершатся - к ним можно переподключиться.

Событие 1057 при старте службы может остаться и дальше: Windows всё равно пытается сделать свой сертификат, но работает на привязанном. Это не мешает.

## Запуск

Скачайте `rdp-cert-fix.exe` из [Releases](../../releases/latest) и запустите - программа сама запросит права администратора. Установка не нужна, зависимостей нет.

Режим без окна для скриптов и удалённого запуска (журнал в `%TEMP%\rdp-cert-fix.log`):

| Ключ | Действие | Код возврата |
|---|---|---|
| `/check` | только проверка | 0 - работает, 3 - сломан, 4 - RDP выключен |
| `/fix` | ремонт и проверка | 0 - успех, 2 - с предупреждениями, 1 - ошибка |

## Сборка

Visual Studio 2022+ с компонентом «Разработка классических приложений на C++». Запустите `build.bat` - получится `rdp-cert-fix.exe` (x64, статический CRT).

Интерфейс - [Dear ImGui](https://github.com/ocornut/imgui) 1.91.9b (MIT) + Direct3D 11, лежит в `vendor/`.
